# 蜻蜓目生成与审核专项规范

## 三次失败证据

- attempt 1：翅膜接近白色不透明，画布外部透明被错误地当成膜质透明。
- attempt 2：简单降低 alpha 导致金褐翅面、翅脉不可辨，并出现红绿彩色噪点。
- attempt 3：膜质和翅脉改善，但只能辨认四条足，缺少中间一对足。

这些结果说明：低 alpha 不等于自然膜质，局部修复也不能替代完整解剖结构。

## 生成硬性要求

1. 恰好四片膜质翅，翅室自然透明或半透明，细暗翅脉在深色和浅色背景下均可辨认。
2. 禁止用整体乳白、金褐填充、彩色噪点或仅降低 alpha 来冒充自然膜质。
3. 六足必须全部可辨，并分别属于前、中、后三对足；不得用遮挡作为缺少中间足的默认解释。
4. 前足位于头胸前方，中足位于翅基附近，后足沿腹部后方延伸；附着点自然，无重复、融合或额外肢体。
5. 保留浅金褐胸部、深黄至焦橙腹部、断续背中线、黑色尾端附器、窄褐色端部标记和短触角。
6. 一只完整个体，所有翅、足、腹部和触角均在画布内，无植物、环境、文字或水印。

## 审核硬性要求

- 分别检查翅膜内部和画布外部，不以画布透明代替翅膜透明。
- 同时查看深色和浅色背景，确认细翅脉清晰、翅室干净且无彩色噪点。
- 逐一列出前、中、后三对足的可见性；缺少任何一对都属于关键解剖失败。
- 精确翅脉、被遮挡的连接点和微小附肢不能由参考证明时，写 `unverifiable`，不得默认正确。
- 任一硬性要求失败即停止，不用整体美观或其他特征抵消关键错误。
