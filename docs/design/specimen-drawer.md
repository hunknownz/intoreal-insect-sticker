# Quiet Taxonomy

秩序不是束缚，而是让生命细节被看见的方式。画面以标本抽屉的精确分隔构成节奏，每个个体都拥有独立而充裕的呼吸空间；网格退居背景，形态、触角、翅脉和色斑成为真正的信息。所有对齐与留白都必须经过细致推敲，呈现长期打磨的工匠感。

色彩取自纸张、墨色与自然体色。暖白不是空白，而是柔和的材料；深灰不是装饰，而是安静的标注。昆虫本体保持鲜明，其他元素主动降低存在感，以极克制的配色衬托专业、可靠的视觉证据。每个像素边缘都应经过大师级检查。

尺度建立观看次序：先看见完整生命，再看见分类关系，最后才是简短文字。个体大小服从统一视觉尺度，不以夸张透视制造廉价冲击，而以真实比例和稳定节奏形成耐看的系列。每一次缩放、裁切和间距调整都要体现精密手工般的用心。

构图追求抽屉式平衡，而非机械平均。轻微的位置变化让画面保持生命感，严谨的基线又使不同物种属于同一系统。文字仅保留名称、分类和必要编号，像标本签一样短小而准确，让空间本身承担解释。

最终作品应当像由顶尖自然史设计团队逐格制作：没有多余装饰，没有仓促拼贴，只有反复校准的形态、材料与秩序。观者在第一眼看見美感，在第二眼看見证据，在更长久的观看中感受到制作时的耐心与敬畏。
